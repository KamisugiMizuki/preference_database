## 优点

1. 诚实的数据呈现（显示 X/共 N 条、双空态、恢复前备份说明）
2. 批量爬图是真产品级流程（i/N 进度 + 四个出口）
3. 破坏性操作防御体系成型（删除带名确认、恢复=橙色 warning+备份承诺）

## 优先问题（修复后）

1. [P1] 背景点击关闭绕过 closeModal → 批量爬图永久挂起（已修：统一走 closeModal）
2. [P1] clearFilters 销毁标签/年份筛选器（已修：改调 loadTagFilter/loadYearFilter）
3. [P1] 空态判定把"类型默认全不勾选"当活跃筛选 → 冷启动误报（已修：类型白名单语义 selectedGenreIds.length>0）
4. [P1] 用户内容未转义拼 innerHTML → 破版+注入风险（已修：escapeHtml 统一转义卡片/详情/表单插值）
5. [P2] 筛选时"共 N 条"为无筛选总数（已修：get_entries_count 接 query 过滤计数）；导出 filtered 带 offset/limit 失真（后端导出本就忽略分页，无实际影响）
6. [P2] 双击保存重复建条目（已修：提交按钮 busy 禁用 + finally 恢复）

## 遗留（未修）

- 脏表单保护（Esc/背景/取消丢未保存内容）
- 错误 toast 直吐 err.message、无修复指引
- 标签只认半角逗号（中文逗号"科幻，治愈"变一个标签）
- 搜索无防抖；详情图片无缓存；桌面零快捷键
- 模态框无 aria-labelledby、无焦点陷阱、× 无 aria-label、缩略图/候选格 click-only
- 分享卡片品牌分裂（Catppuccin vs 主 UI）；genre 色板未升级为主视觉
- --genre-* CSS token 死代码（真值在 main.ts 双源）
- .filter-item .count 死 CSS；视图切换不持久化；恢复后勾选残留
